Component Thinking Reflection

Thinking in components changed the way I structured my code because I stopped creating every UI element separately. Instead, I created reusable functions that receive data through parameters and generate the required elements. This made my code more organized, reduced repetition, and made it easier to update the UI. It also helped me understand how reusable components and props work in frameworks like React.
